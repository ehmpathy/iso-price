## D1 — `"private": true` backfilled onto a public npm package

### classification: repo quirk (primary) + practice gap (secondary)

**repo quirk** — iso-price is a public repo that publishes to npm. it must declare `"private": false` explicitly. HEAD left the key absent, which the new practice reads as "visibility implicit".

**practice gap** — the backfill picks `true` for every repo, public npm packages included. the result on a public package:
- `npm publish` refuses → release breaks silently until a tag
- provision plan proposes public → private

### citation

practice: `provision-github` → bad-practice `implicit-package-privacy`

- `check` detects `typeof pkg.private !== 'boolean'`; `fix` sets `private: true`
- line 31: `// an explicit boolean is the owner's choice; never touch it` → our `"private": false` is durable across future upgrades
